# IMovies

**A full-stack movie ticket booking and cinema management platform.**

IMovies is an individual software development project built using the MERN
stack. It aims to simplify movie discovery, showtime selection, seat booking,
and cinema administration.

## Objectives

- Provide a convenient movie browsing experience.
- Support secure user authentication.
- Enable showtime selection and seat booking.
- Manage bookings and simulated payments.
- Provide administrative tools for managing movies, theatres, and shows.

## Technology Stack

| Component | Technology |
|---|---|
| Frontend | React, JavaScript, Bootstrap |
| Backend | Node.js, Express.js |
| Database | MongoDB, Mongoose |
| Authentication | JWT, bcryptjs |
| Version Control | Git, GitHub |

## Planned Features

- Movie search and filtering
- Movie details and showtimes
- User registration and login
- Interactive seat selection
- Ticket booking and confirmation
- Simulated payment workflow
- Booking history and cancellation
- Admin dashboard
- Movie, theatre, and show management
